# Security Policy

## Supported versions

Security fixes are applied to the latest `main` branch. This project is experimental software and should not be used with funds you cannot afford to lose.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Until a dedicated security contact is published, contact the repository maintainers privately through GitHub with:

- a clear description and impact;
- reproduction steps or a minimal proof of concept;
- affected commit, route, or component;
- any suggested mitigation.

Please redact private keys, wallet seed phrases, API tokens, and personal data. We will acknowledge reports and coordinate disclosure after a fix is available.

## Important safety note

Entropy Roulette can construct and broadcast real Bitcoin transactions. Always review the network, inputs, outputs, fees, and payout address in a wallet before signing. Never commit secrets or production credentials to this repository.
